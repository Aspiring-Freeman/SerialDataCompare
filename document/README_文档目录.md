## 命名规范

- **静态文档** — 不带日期，直接使用描述性名称：`功能说明.md`
- **版本文档** — 带日期或版本号：`使用指南_20251101.md`、`快速使用指南_v1.3.0.md`
- **发布说明** — 放入 `Release_Notes/` 子目录
